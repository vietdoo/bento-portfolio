# 🍱 vietdoo — Bento Portfolio

A clean, modern bento-style personal portfolio website built with **Astro**, **SolidJS**, **Svelte**, **UnoCSS**, and **Three.js**.

## 🛠️ Tech Stack

- **Framework:** [Astro](https://astro.build)
- **UI & Components:** [SolidJS](https://www.solidjs.com/), [Svelte](https://svelte.dev/), [UnoCSS](https://unocss.dev/)
- **3D & Animation:** [Three.js](https://threejs.org/), [Cannon.es](https://pmndrs.github.io/cannon-es/), [Motion](https://motion.dev/)
- **Database & Backend:** [Astro DB](https://astro.build/db), Netlify Functions

## 🚀 Quick Start

```bash
# Install dependencies
pnpm install

# Start local dev server
pnpm dev
```
